# ✨ Animagia - API de Chaves & Chapolin

Bem-vindo ao **Animagia**, um ecossistema digital dedicado a preservar e transmitir um mega acervo com **1.000 episódios** clássicos, raros e perdidos das séries **Chaves** e **Chapolin** (500 episódios de cada).

O projeto conta com uma interface web de streaming integrada, paginação otimizada e sistema de filtros por série.

---

## 🚀 Tecnologias Utilizadas

- **Python** (Linguagem principal)
- **FastAPI** (Framework web de alta performance)
- **SQLAlchemy** (ORM para gerenciamento do banco de dados)
- **SQLite** (Banco de dados leve e embutido)
- **HTML5 / CSS3** (Interface de streaming responsiva)

---

## 📦 Estrutura do Projeto

- `main.py` — Configuração principal do FastAPI, rotas da API e interface visual de streaming.
- `database.py` — Configuração da conexão com o banco de dados e sessão.
- `models.py` — Definição do modelo de dados para os episódios.
- `requirements.txt` — Lista de dependências e bibliotecas do projeto.
